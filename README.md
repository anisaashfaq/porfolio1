# Anisa Ashfaq — Portfolio

A professional single-page portfolio website showcasing experience, education, projects, and skills.

## Sections

- **Hero** — Name, role, value statement, CTAs
- **About** — Professional summary
- **Experience** — AllSpice Technologies (timeline format)
- **Education** — BS CS, FSc, Matriculation
- **Projects** — 6 projects with problem, role, features, links
- **Skills** — Organized by Languages, Tools, Soft Skills
- **Contact** — Email, LinkedIn, GitHub, CV download

## Getting Started

1. **Add your CV** — Place your resume PDF at:
   ```
   assets/Anisa-Ashfaq-CV.pdf
   ```
   The "Download CV" buttons link to this file.

2. **Open the site** — Double-click `index.html` or use a local server:

   ```bash
   # Python
   python -m http.server 8080

   # Node (npx)
   npx serve .
   ```

   Then visit `http://localhost:8080`

## Deploy

Upload the entire folder to:

- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://www.netlify.com/) (drag & drop)
- [Vercel](https://vercel.com/)

No build step required — static HTML, CSS, and JavaScript.

## Customize

- Edit content in `index.html`
- Adjust colors and fonts in `css/styles.css` (`:root` variables)
- Behavior (nav, scroll) in `js/main.js`
